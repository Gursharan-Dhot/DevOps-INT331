📖 Docker Command Structure

🔧 Understanding Docker CLI Syntax

docker [OPTIONS] COMMAND [ARG...]
docker

Base command

[OPTIONS]

Global flags
--version, --help

COMMAND

Action to perform
run, pull, build

[ARG...]

Command arguments
image:tag

-d, --detach Run container in background
-i, --interactive Keep STDIN open even if not attached
-t, --tty Allocate a pseudo-TTY
-p, --publish Publish container port to host
-v, --volume Bind mount a volume
--name Assign a name to the container

💡 Command Building Strategy

Start simple, add complexity:

docker run nginx # Basic docker run -d nginx # Add background docker run -d -p 8080:80 nginx # Add port mapping docker run -d -p 8080:80 --name web nginx # Add custom name

📦 Image Management Commands

⚙️ Container Control Operations

docker start / stop
Start or stop existing containers
# Start stopped container docker start my-web # Stop running container docker stop my-web # Restart container docker restart my-web # Start multiple containers docker start web1 web2 web3 # Stop all running containers docker stop $(docker ps -q)
docker pause / unpause
Suspend/resume container processes
# Pause container (suspend processes) docker pause my-web # Unpause container (resume processes) docker unpause my-web # Pause multiple containers docker pause web1 web2 # Useful for temporary resource management docker pause $(docker ps --format "{{.Names}}")
docker kill
Force kill container (SIGKILL)
# Force kill container docker kill my-web # Kill with specific signal docker kill --signal=SIGTERM my-web # Kill all running containers docker kill $(docker ps -q) # Kill container by partial name docker kill $(docker ps --filter name=web -q)

🔧 Interacting with Containers

docker exec
Execute commands in running container
# Get interactive shell docker exec -it my-web bash # Execute single command docker exec my-web ls -la /usr/share/nginx/html # Execute as different user docker exec -u root my-web whoami # Execute with environment variables docker exec -e VAR=value my-web env
docker cp
Copy files between container and host
# Copy from host to container docker cp ./index.html my-web:/usr/share/nginx/html/ # Copy from container to host docker cp my-web:/var/log/nginx/access.log ./logs/ # Copy directory docker cp ./static my-web:/usr/share/nginx/html/ # Copy with archive mode (preserve permissions) docker cp -a ./config my-web:/etc/
docker top
Display running processes in container
# Show processes in container docker top my-web # Show processes with custom format docker top my-web aux # Monitor specific container processes docker top my-web -ef

🗑️ Container Cleanup

docker rm
Remove one or more containers
# Remove stopped container docker rm my-web # Force remove running container docker rm -f my-web # Remove multiple containers docker rm web1 web2 web3 # Remove by container ID docker rm abc123 # Remove all stopped containers docker rm $(docker ps -aq --filter status=exited)
docker container prune
Remove all stopped containers
# Remove all stopped containers docker container prune # Remove without confirmation docker container prune -f # Remove containers older than 24 hours docker container prune --filter "until=24h" # Show what would be removed (dry run) docker container prune --filter "until=1h" --dry-run

🖥️ CLI vs Docker Desktop GUI

⚖️ Command Line vs Graphical Interface

💻 Command Line Interface

Advantages:

  • Speed: Faster for experienced users
  • Automation: Easy to script and automate
  • Precision: Exact control over all options
  • Remote: Works over SSH connections
  • CI/CD: Perfect for build pipelines

Best for: Production, automation, power users

🖱️ Docker Desktop GUI

Advantages:

  • Visual: Easy to see container status
  • Intuitive: Point-and-click operations
  • Learning: Great for beginners
  • Monitoring: Built-in resource graphs
  • Logs: Easy log viewing and filtering

Best for: Development, learning, monitoring

🎯 Common Tasks: CLI vs GUI

📦 Task: Run nginx web server on port 8080
CLI Method:
docker run -d -p 8080:80 --name my-web nginx:alpine
GUI Method:
  1. Open Docker Desktop
  2. Go to Images → Search nginx
  3. Click Run button
  4. Configure ports: 8080:80
  5. Set container name: my-web
  6. Click Run
📊 Task: View container logs
CLI Method:
docker logs -f my-web
GUI Method:
  1. Open Docker Desktop
  2. Go to Containers
  3. Click on container name
  4. Click "Logs" tab
  5. Toggle "Follow logs" if needed
🧹 Task: Clean up unused containers and images
CLI Method:
docker system prune -a # or individually: docker container prune docker image prune -a docker volume prune
GUI Method:
  1. Open Docker Desktop
  2. Go to Settings → Resources
  3. Click "Clean / Purge data"
  4. Select what to clean
  5. Confirm deletion
💻 Task: Access container shell
CLI Method:
docker exec -it my-web bash # or docker exec -it my-web sh
GUI Method:
  1. Open Docker Desktop
  2. Go to Containers
  3. Click container name
  4. Click "Terminal" or "CLI" tab
  5. Select shell type (bash/sh)

💡 Best Practice: Use Both!

  • Learning: Start with GUI to understand concepts
  • Development: Use GUI for monitoring and debugging
  • Production: Use CLI for automation and scripting
  • Troubleshooting: GUI for quick visual checks, CLI for detailed investigation

🔧 System & Maintenance Commands

docker info
Display system-wide information
# Show Docker system info docker info # Key information includes: # - Server version # - Storage driver # - Running containers # - Images count # - CPU and memory info
docker version
Show Docker version information
# Show version info docker version # Short version docker --version # Format output docker version --format '{{.Server.Version}}'
docker system
System-wide management commands
# Show disk usage docker system df # Clean up everything docker system prune # Clean up everything including volumes docker system prune --volumes # Show detailed disk usage docker system df -v
docker events
Get real-time events from server
# Stream real-time events docker events # Show events since specific time docker events --since="2023-01-01" # Filter events by type docker events --filter event=start # Show events for specific container docker events --filter container=my-web

⚠️ Windows-Specific Considerations

  • File Paths: Use forward slashes or escape backslashes: C:/Users/ or C:\\Users\\
  • Drive Letters: Mount Windows drives as /mnt/c/ in containers
  • Line Endings: Be aware of CRLF vs LF when copying files
  • Permissions: Windows file permissions work differently in containers
  • PowerShell vs CMD: Some commands may behave differently in PowerShell
# Windows-specific examples # Mount Windows directory docker run -v C:/Users/username/project:/app ubuntu # Use PowerShell variables docker run -e "DB_HOST=$env:DB_HOST" myapp # Handle spaces in paths docker run -v "C:/Program Files/data:/data" myapp # Convert line endings docker run --rm -v C:/project:/src alpine dos2unix /src/*.sh

🔍 Discovering & Pulling Images

docker search
Search Docker Hub for images
# Basic search docker search nginx # Search with filters docker search --filter stars=100 python docker search --filter is-official=true mysql docker search --limit 10 ubuntu
docker pull
Download images from registry
# Pull latest version docker pull nginx # Pull specific version docker pull nginx:1.21-alpine # Pull from specific registry docker pull gcr.io/google-containers/nginx

📋 Listing & Inspecting Images

docker images
List all local images
# List all images docker images # Alternative syntax docker image ls # Show all images (including intermediate) docker images -a # Filter by repository docker images nginx
docker inspect
Detailed information about images
# Inspect image details docker inspect nginx:latest # Get specific information (JSON query) docker inspect --format='{{.Config.Env}}' nginx # Check image size docker inspect --format='{{.Size}}' nginx
docker history
Show image layer history
# View image layers docker history nginx:latest # Show full commands (no truncation) docker history --no-trunc nginx # Human readable sizes docker history --human nginx

🗑️ Cleaning Up Images

docker rmi
Remove one or more images
# Remove specific image docker rmi nginx:latest # Remove multiple images docker rmi nginx ubuntu python # Force removal docker rmi -f nginx:latest # Remove by image ID docker rmi abc123def456
docker image prune
Remove unused images
# Remove dangling images docker image prune # Remove all unused images docker image prune -a # Remove without confirmation docker image prune -f # Remove with filters docker image prune --filter "until=24h"

🚀 Creating & Running Containers

docker run
Create and start container in one command
# Basic run docker run nginx # Run in background docker run -d nginx # With port mapping docker run -d -p 8080:80 nginx # Interactive mode docker run -it ubuntu bash # Complete example docker run -d -p 8080:80 --name my-web nginx
docker create
Create container without starting
# Create container docker create --name my-app nginx # Create with configuration docker create -p 8080:80 --name web nginx # Create with environment variables docker create -e DB_HOST=localhost nginx

📋 Listing & Monitoring Containers

docker ps
List containers
# List running containers docker ps # List all containers (including stopped) docker ps -a # Show only container IDs docker ps -q # Show latest created container docker ps -l # Custom format docker ps --format "table {{.Names}}\t{{.Status}}"
docker stats
Real-time resource usage statistics
# Show stats for all running containers docker stats # Show stats for specific container docker stats my-web # Show stats once (no streaming) docker stats --no-stream # Show stats without formatting docker stats --no-trunc
docker logs
View container logs
# View logs docker logs my-web # Follow logs (like tail -f) docker logs -f my-web # Show last 50 lines docker logs --tail 50 my-web # Show logs with timestamps docker logs -t my-web
