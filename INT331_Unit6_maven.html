🔧 What is Apache Maven?
🏗️

Build Automation

Automatically compiles, tests, and packages your Java projects

📦

Dependency Management

Downloads and manages external libraries your project needs

📁

Project Structure

Enforces standard directory layout and project organization

🎯

Convention over Configuration

Sensible defaults mean less configuration, more productivity

🤔 Why do we need Maven?

Before Maven: Manual compilation, managing JAR files, complex build scripts, inconsistent project structures

With Maven: Automated builds, dependency resolution, standardized structure, reproducible builds

Maven solves these problems:

  • Managing external dependencies (JAR files)
  • Compiling source code in the right order
  • Running tests automatically
  • Packaging applications for deployment
  • Maintaining consistent project structure
  • Sharing projects with teams

📂 Maven Project Structure

Standard Directory Layout

my-maven-app/ ├── pom.xml # Project configuration └── src/ ├── main/ │ ├── java/ # Production Java code │ │ └── com/ │ │ └── example/ │ │ └── App.java │ └── resources/ # Configuration files └── test/ └── java/ # Test code └── com/ └── example/ └── AppTest.java

✅ Benefits of Standard Structure

  • Every Maven project looks the same
  • IDEs automatically recognize Maven projects
  • No configuration needed for basic setup
  • Easy to navigate and understand
📄 POM.xml - Project Object Model

The Heart of Every Maven Project

<project> <!-- Project Coordinates (GAV) --> <groupId>com.example</groupId> <artifactId>my-maven-app</artifactId> <version>1.0.0</version> <!-- Dependencies --> <dependencies> <dependency> <groupId>junit</groupId> <artifactId>junit</artifactId> <version>4.13.2</version> <scope>test</scope> </dependency> </dependencies> </project>

🪟 Windows 10 Setup Guide

Prerequisites Installation

⚠️ Before Starting

Make sure you have Administrator privileges on your Windows machine

  1. Install Java JDK 11+
    • Download from Adoptium
    • Run installer as Administrator
    • Verify: Open Command Prompt and run java -version
  2. Install Maven
    • Download from Apache Maven
    • Extract to C:\apache-maven-3.x.x
    • Add to PATH: C:\apache-maven-3.x.x\bin
    • Verify: mvn -version

Create Project Structure

REM Create directories mkdir my-maven-app cd my-maven-app mkdir src\main\java\com\example mkdir src\test\java\com\example REM Create files type nul > pom.xml type nul > src\main\java\com\example\App.java type nul > src\test\java\com\example\AppTest.java
👨‍💻 Hands-on Project: Hello World Maven App

1. Create pom.xml

<?xml version="1.0" encoding="UTF-8"?> <project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd"> <modelVersion>4.0.0</modelVersion> <groupId>com.example</groupId> <artifactId>my-maven-app</artifactId> <version>1.0.0</version> <packaging>jar</packaging> <name>My Maven App</name> <properties> <maven.compiler.source>11</maven.compiler.source> <maven.compiler.target>11</maven.compiler.target> <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding> </properties> <dependencies> <dependency> <groupId>junit</groupId> <artifactId>junit</artifactId> <version>4.13.2</version> <scope>test</scope> </dependency> </dependencies> </project>

2. Create App.java

package com.example; /** * Hello world application */ public class App { public static void main(String[] args) { System.out.println("Hello World from Maven!"); App app = new App(); String greeting = app.getGreeting("Maven"); System.out.println(greeting); } public String getGreeting(String name) { return "Hello, " + name + "! Welcome to build automation."; } }

3. Create AppTest.java

package com.example; import org.junit.Test; import static org.junit.Assert.*; /** * Unit test for App class */ public class AppTest { @Test public void testGetGreeting() { App app = new App(); String result = app.getGreeting("World"); assertEquals("Hello, World! Welcome to build automation.", result); } @Test public void testGetGreetingWithMaven() { App app = new App(); String result = app.getGreeting("Maven"); assertEquals("Hello, Maven! Welcome to build automation.", result); } }

🔧 Common Issues & Troubleshooting

Windows-Specific Issues

⚠️ "mvn is not recognized as an internal or external command"

Problem: Maven not in system PATH

Solution:

  1. Right-click "This PC" → Properties
  2. Advanced System Settings → Environment Variables
  3. Edit "Path" variable
  4. Add: C:\apache-maven-3.x.x\bin
  5. Restart Command Prompt

⚠️ "JAVA_HOME not found"

Problem: Java environment variable not set

Solution:

  1. Find Java installation: where java
  2. Create JAVA_HOME variable pointing to JDK folder
  3. Example: C:\Program Files\Eclipse Adoptium\jdk-11.0.19.7-hotspot

Build Issues

mvn clean
🧹 Clean build artifacts
Solves most build issues
mvn dependency:tree
🌳 Show dependency tree
Debug dependency conflicts
mvn help:effective-pom
📄 Show effective POM
See resolved configuration

Quick Fixes Checklist

  • Restart Command Prompt after PATH changes
  • Check internet connection for dependency downloads
  • Verify Java version: java -version
  • Verify Maven version: mvn -version
  • Run mvn clean before other commands
  • Check for typos in pom.xml
  • Ensure proper directory structure
