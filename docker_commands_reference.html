🐳 Essential Docker Commands

Quick Reference Guide for Daily Use
📦

Image Commands

docker pull
Download an image from registry
docker pull nginx:alpine
docker images
List all local images
docker images
docker rmi
Remove one or more images
docker rmi nginx:alpine
docker search
Search Docker Hub for images
docker search python
docker tag
Create a tag for an image
docker tag nginx:latest myapp:v1
🐳

Container Commands

docker run
Create and start a new container
docker run -d -p 8080:80 nginx
docker ps
List running containers
docker ps -a
docker stop
Stop one or more containers
docker stop my-container
docker start
Start one or more stopped containers
docker start my-container
docker restart
Restart one or more containers
docker restart my-container
docker rm
Remove one or more containers
docker rm my-container
docker exec
Execute command in running container
docker exec -it container bash
docker logs
Fetch container logs
docker logs -f my-container
docker cp
Copy files between container and host
docker cp file.txt container:/path
🌐

Network & Volume Commands

docker network ls
List all networks
docker network ls
docker network create
Create a new network
docker network create my-net
docker volume ls
List all volumes
docker volume ls
docker volume create
Create a new volume
docker volume create my-vol
🔨

Build & Registry Commands

docker build
Build image from Dockerfile
docker build -t myapp:latest .
docker push
Push image to registry
docker push username/myapp:latest
docker login
Log in to Docker registry
docker login
docker logout
Log out from Docker registry
docker logout
⚙️

System Commands

docker info
Display system information
docker info
docker version
Show Docker version information
docker --version
docker stats
Display live resource usage
docker stats
docker system prune
Remove unused resources
docker system prune -a

🚀 Most Common Usage Patterns

Quick Start

docker run -d nginx Start web server
docker ps Check status
docker stop container_id Stop it

Interactive Mode

docker run -it ubuntu bash Get shell
docker exec -it container bash Connect to running
exit Leave container

With Ports & Volumes

docker run -p 8080:80 nginx Port mapping
docker run -v /host:/container nginx Volume mount
docker run -e VAR=value nginx Environment

Cleanup Commands

docker container prune Remove stopped
docker image prune Remove unused images
docker system prune -a Clean everything

💡 Pro Tips

  • Use specific tags: nginx:1.21-alpine instead of nginx:latest
  • Name your containers: --name my-web for easy reference
  • Clean up regularly: docker system prune to free disk space
  • Check logs for debugging: docker logs container_name

⚠️ Important Notes

  • Windows paths: Use forward slashes or escape backslashes
  • Port conflicts: Each port can only be used by one container
  • Data persistence: Use volumes to keep data after container removal
  • Resource limits: Monitor CPU and memory usage with docker stats
